Sync across devices

Not connected

Keeps your bets, API keys and scan settings the same on your PC and phone. Data is encrypted with your sync password before it is saved to a private GitHub repository you own.

How to set this up
  1. On GitHub, create a new private repository (e.g. arbscan-data) and tick "Add a README file".
  2. GitHub → your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories, choose arbscan-data. Permissions → Repository permissions → Contents: Read and write. Generate and copy the token.
  4. Enter the repository, token and a sync password here, then Save. Do the same on your other device.
